# InferenceEndpointJobCollection

Represents a collection of inference endpoint jobs

**Properties**

| Name      | Type                   | Required | Description                                  |
| :-------- | :--------------------- | :------- | :------------------------------------------- |
| items     | InferenceEndpointJob[] | ✅       | The list of inference endpoint jobs.         |
| page      | number                 | ✅       | The page number.                             |
| pageSize  | number                 | ✅       | The maximum number of items per page.        |
| totalSize | number                 | ✅       | The total number of items in the collection. |
