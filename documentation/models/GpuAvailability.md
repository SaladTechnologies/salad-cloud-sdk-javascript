# GpuAvailability

**Properties**

| Name               | Type   | Required | Description                             |
| :----------------- | :----- | :------- | :-------------------------------------- |
| availableGpuBatch  | number | ❌       | The number of available GPU batches     |
| availableGpuLow    | number | ❌       | The number of available low-end GPUs    |
| availableGpuMedium | number | ❌       | The number of available medium-end GPUs |
| availableGpuHigh   | number | ❌       | The number of available high-end GPUs   |
| onCallGpu          | number | ❌       | The number of on-call GPUs available    |
